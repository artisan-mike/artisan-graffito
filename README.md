# Artisan Graffito

This app lets users to draw in the browser in a sketchy way, save their work and load them.

# How to run localy

    - `pnpm i`
    - `pnpm dev`

# Poject structure

    - `components` contains the project sharable and page specific components
    - `lib` contains utility functions and hooks
    - `store` contains state management codes
